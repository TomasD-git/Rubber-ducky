# Rubber Ducky  



## Small Rubber Ducky, supports standard rubber ducky code, with website interface.  



## Features:  
**Supports standard rubber ducky code**  
**Website interface over wifi**  
**Pretty small**  
**Wifi + Bluetooth**

<details>
<summary>How to make?</summary>
  
First buy PCB, with stencil if u dont trust your soldering skills or without if u do.
then all components in the bom, u can skip solder paste, kapton tape, hot air station if u have these, once arrived 3D print case solder 4 core cable, plug usbc into pc, flash and then just assemble and you are ready.

</details>
